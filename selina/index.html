Commands Ready Now

A pick of what's already live. There's more, this is the good stuff.

Moderation

/automod-ai Configure AI-powered auto-moderation
/ban Bans a user from the server
/kick Kicks a user from the server
/mute Timeout (mute) a member
/warn Manage user warnings
/clear Delete multiple messages at once
/serverlock Lock or unlock the entire server or specific channels
/slowmode Set slowmode for the channel
/role Manage user roles

(and more...)

Utility

/fn-serverstatus Manage Fortnite server status updates
/serverstats View server activity analytics
/serverinfo Displays information about the server
/userinfo Displays information about a user
/avatar Shows a user's avatar
/anime Get anime information
/afk Set your AFK status
/servericon Display the server icon in high resolution
