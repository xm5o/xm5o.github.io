# Public Profile Finder

A mobile-friendly static web app for checking public username matches across common social platforms.

## What it does

- Accepts one or two usernames.
- Builds candidate public profile links for Instagram, TikTok, Snapchat, X, YouTube, Twitch, GitHub, Reddit and Pinterest.
- Builds focused Google search links for each username/platform pair.
- Lets you manually mark profiles you verified from public information.

## Privacy boundaries

This project checks public information only.

It does not use phone-number lookup, leaked databases, private-account bypasses, location tracking, login/session scraping, or claims that a matching username proves two accounts belong to the same person.
